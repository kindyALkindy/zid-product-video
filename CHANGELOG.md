# Changelog

## 1.0.0 - 2026-08-12

### Added

- Initial TypeScript release.
- Native `zid-product-video` custom element.
- YouTube URL parsing.
- Lazy iframe loading.
- Autoplay, muted, loop, controls, and playsinline support.
- Optional YouTube privacy-enhanced mode.
- Poster support.
- CSS custom properties.
- Zid/Jinja usage support.
